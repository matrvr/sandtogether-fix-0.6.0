# SandTogether — фикс под Sandustry 0.6.0

Неофициальный фикс для мода [SandTogether](https://github.com/IronBamBam1990/sandtogether)
(автор — Kamil Padula, лицензия MIT; [мастерская Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3784750764)).
Версия мода с фиксом: **0.9.287-beta-fix2** (её показывает панель мода и лог).

## Что исправлено

1. **`patches.json` — поддержка игры 0.6.0.** Мод 0.9.287-beta поддерживает Sandustry только до 0.5.7.
   На 0.6.0 в код игры вставлялось ~5 из 42 хуков мода, поэтому копание, постройки, пылесос, спрей,
   снаряды, существа, трубы и т.д. у одного из игроков не работали или не синхронизировались.
   Добавлены варианты всех 42 хуков под 0.6.0, старые оставлены.
2. **`sandtogether.js` — зависание синхронизации мира (fix2).** Хост сжимает каждый пакет мира перед
   отправкой и ждёт, пока сжатие закончится. Если сжатие не возвращало результат, отправка мира у хоста
   останавливалась навсегда и без ошибки в логе: у клиента переставало работать всё, и не помогали ни
   Resync, ни перезаход. Теперь у сжатия лимит 5 секунд: при зависании пакет пропускается, его данные
   возвращаются в очередь, отправка продолжается.

## Установка (ОБОИМ игрокам, игра закрыта)

1. Скачайте [`patches.json`](patches.json) и [`sandtogether.js`](sandtogether.js)
   (на странице файла — кнопка Download raw file).
2. Замените ими файлы с теми же именами в папке `src` мода:
   - **Windows:** `<библиотека Steam>\steamapps\workshop\content\2764460\3784750764\src\`
   - **macOS:** `~/Library/Application Support/Steam/steamapps/workshop/content/2764460/3784750764/src/`
     (в Finder: Cmd+Shift+G и вставить путь)
3. Запустите установщик из папки `3784750764`:
   - **Windows:** `install.bat`
   - **macOS:** двойной клик по `install.command`

   В выводе должно быть 42 строки `[+] bundle.js: ...` и ни одной строки `[!] skipped`.
4. Запустите игру (на macOS — через `SandTogether-Launch.command`).
   В панели мода/логе должна быть версия `0.9.287-beta-fix2` у обоих.

Если Steam обновит мод или игру, фикс может слететь — повторите шаги 2–3.
Если в мастерской выйдет версия мода с поддержкой 0.6.0, этот фикс больше не нужен.

## Лог (если что-то сломалось)

- **Windows:** `%APPDATA%\Sandustry\logs\main.log`
- **macOS:** `~/Library/Logs/` → папка игры → `main.log`
